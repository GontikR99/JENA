JENA: EverQuest triggers in your browser

Jephine's Event Notification Apparatus is a web-based EverQuest trigger tool. It reads local EverQuest log files from a directory you choose, watches for matching trigger text, and shows timers, text alerts, speech alerts, and other trigger actions while you play.

To get started, open or choose your EverQuest directory, then start triggers. JENA opens a small overlay window that can be moved over your EverQuest window to display active timers and alerts.

Web-only trigger monitoring

JENA runs in the browser and does not require a full desktop trigger program. The optional JENA Companion app is available only for browser-limited features such as native clipboard support.

Publish triggers

Logged-in users can publish their selected trigger set and receive a shareable subscription code. When the publisher changes published triggers, subscribers receive updated trigger information automatically.

Subscribe to triggers

Anyone can subscribe to a published trigger set with a JENA subscription code. Subscriptions can be trusted for automatic future trigger updates, reviewed trigger by trigger, or removed entirely.

Broadcast alerts

Trigger broadcasts can share important alerts across your own boxes or to subscribers. This is useful when one character sees an event that other characters or raid members should react to, such as a raid mechanic, mask click, emote, or timer event.

GINA package import and export

JENA can import GINA trigger package files and export trigger packages, making it easier to move existing EverQuest trigger collections into or out of JENA.

Companion app

Clipboard actions require the optional Windows companion app because browsers intentionally restrict background clipboard writes. The companion installer is available at /downloads/jena-companion-setup.exe.
